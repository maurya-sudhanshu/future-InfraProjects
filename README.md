## 📌 Overview

**Future InfraProjects** is an Angular application scaffolded with Angular CLI 15. The repository includes the core Angular project configuration and dependencies for building component-based user interfaces, routing, forms, animations, and carousel content.

Use this repository as the starting point for developing and maintaining the application’s frontend.

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm versions compatible with Angular CLI 15
- Git

### 1. Clone the repository

```bash
git clone https://github.com/maurya-sudhanshu/future-InfraProjects.git
cd future-InfraProjects
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

Open [http://localhost:4200](http://localhost:4200). The Angular development server reloads the application when source files change.

## 📜 Available Scripts

| Command | Description |
|---|---|
| `npm start` | Start the Angular development server |
| `npm run ng -- --help` | Show Angular CLI help |
| `npm run build` | Build the application |
| `npm run watch` | Rebuild automatically during development |
| `npm test` | Run unit tests with Karma |

## 🗂️ Project Structure

```text
future-InfraProjects/
├── src/                 # Angular application source
├── angular.json         # Angular CLI configuration
├── package.json         # Scripts and dependencies
├── package-lock.json    # Locked dependency tree
├── tsconfig.json        # TypeScript configuration
├── tsconfig.app.json    # App TypeScript configuration
└── tsconfig.spec.json   # Test TypeScript configuration
```

The exact pages, components, and services are maintained under `src/`.

## 🧑‍💻 Development Tips

- Keep components focused and reusable.
- Use Angular services for shared business logic and data access.
- Prefer typed models and clear interfaces for application data.
- Keep environment-specific configuration out of committed secrets.
- Add or update unit tests when changing application behavior.
- Review dependencies and plan framework upgrades deliberately.

## 🧪 Testing & Production Build

Run the unit tests:

```bash
npm test
```

Create a production build:

```bash
npm run build
```

The generated output is written to the Angular build output directory configured in `angular.json` (commonly `dist/`).
